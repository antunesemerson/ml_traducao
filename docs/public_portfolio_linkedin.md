# Divulgação e Portfólio: ML Tradução CK3 PT-BR

Este documento consolida a narrativa pública do projeto ML Tradução CK3 PT-BR para LinkedIn, portfólio e materiais visuais.

O foco é apresentar o projeto como um produto real publicado, com usuários reais, e também como experiência prática de Machine Learning, NLP, engenharia de dados, automação, validação e melhoria contínua.

## Texto Principal Para LinkedIn

Traduzir um jogo de nicho parece simples... até você se deparar com 288 mil linhas de texto dinâmico, variáveis complexas e frases que mudam conforme personagem, cultura, fé, título, gênero, evento e contexto medieval.

Esse foi o tamanho real do desafio por trás do mod PT-BR de *Crusader Kings III* que venho desenvolvendo e publicando na Steam Workshop e na Paradox Mods.

Hoje o projeto já soma 793 inscritos/subscribers nas duas stores, com 833 acessos únicos na Steam, e segue evoluindo com feedback de jogadores reais.

Mas o mais interessante para mim não foi apenas traduzir o jogo.

Foi construir um sistema para traduzir, validar, comparar, proteger e melhorar continuamente essa tradução.

Para lidar com isso, construí uma pipeline neuro-simbólica com:

- processamento de alta volumetria, com cerca de 288 mil segmentos de localização;
- Machine Learning, NLP, agentes e regras especializadas;
- validação de tokens, variáveis, scopes e estrutura YAML;
- comparação de qualidade entre baseline e output;
- score por segmento e score ponderado do pacote;
- filas de promoção, apply, regressão, baixo score e revisão manual;
- aprendizado local a partir de decisões humanas e feedback visual do jogo;
- dry-run, snapshots, rollback e apply protegido antes de qualquer escrita crítica.

A ideia central do projeto é simples:

```text
🧠 ML recomenda.
🛡️ Regras protegem.
✅ Humano confirma.
```

Esse projeto virou meu laboratório prático de Machine Learning responsável: não uma automação cega, mas uma arquitetura de apoio à decisão, com rastreabilidade, governança, controle de risco e produto real em produção.

E talvez essa seja a parte mais legal: o sistema não nasceu em um case fictício. Ele nasceu de um problema real, com jogadores reais, bugs reais, métricas reais e melhoria contínua de verdade.

Próxima etapa: fechar a nova versão do mod com mais correções validadas, melhorar ainda mais a confiabilidade por segmento e transformar o feedback da comunidade em aprendizado para o sistema.

## Versão Curta

Estou desenvolvendo um sistema de tradução, validação e melhoria contínua para um mod brasileiro de *Crusader Kings III*, já publicado na Steam Workshop e na Paradox Mods, com 793 inscritos/subscribers somados.

O projeto combina Machine Learning, NLP, engenharia de dados, automação e revisão humana para lidar com cerca de 288 mil segmentos de localização, preservando tokens dinâmicos, estrutura YAML, gênero, cultura, fé, títulos, contexto medieval e fluidez PT-BR.

A lógica do sistema é simples:

```text
ML recomenda.
Regras protegem.
Humano confirma.
```

Mais do que uma tradução, é um produto real com usuários reais e uma arquitetura de melhoria contínua baseada em diagnóstico, validação, dry-run, snapshots, rollback e apply protegido.

## Formas De Apresentação Visual

### Carrossel Para LinkedIn

Bom para uma narrativa em etapas.

Deve funcionar como uma história visual, não como slide técnico. Cada tela precisa ter uma ideia central, pouco texto e um print ou dado visual forte.

### Vídeo Curto

Melhor formato para mostrar transição suave entre problema, arquitetura e produto publicado.

Estrutura sugerida:

```text
jogo/mod publicado
  -> problema da localização dinâmica
  -> tokens e estrutura
  -> rede de agentes
  -> dashboard/KPIs
  -> apply protegido
  -> mod nas stores
```

### Página Web De Prévia

Boa para montar, visualizar e ajustar o carrossel antes de exportar.

Pode conter:

- cenas em sequência;
- imagens reais;
- KPIs;
- microanimações;
- transições suaves;
- versão de portfólio expandida.

O LinkedIn não renderiza uma página interativa diretamente dentro do post. A página web funciona melhor como portfólio externo ou como estúdio local para gerar imagens/vídeo.
